# Админ Панель - Инструкция

## Доступ

Админ панель доступна по адресу `/admin` и открывается только для пользователя с ID = 1 (администратор).

## Функционал

### 1. Анализ Продаж (Sales Analytics)

- **Объём продаж** - Общая сумма заказов за выбранный период
- **Себестоимость** - Сумма расходов на товары (вычисляется на основе `costPrice` группы товара)
- **Gross Profit** - Разница между объёмом и себестоимостью
- **Маржа** - Процент прибыли от объёма

Периоды: День, Неделя, Месяц

### 2. ТОП Товары (Top Products)

- **ТОП-10 по Объёму** - Товары, принёсшие наибольшую сумму продаж
- **ТОП-10 по Прибыли** - Товары с наибольшей прибылью

### 3. Анализ Дилеров (Dealer Analytics)

- Список всех дилеров, отсортированный по объёму закупок в денежном выражении
- Показывает количество заказов каждого дилера

### 4. Отслеживание Долгов (Debt Tracking)

Вычисляется как: **Сумма Обычных Заказов + (Реализация Отгружено - Реализация Оплачено)**

- **Состояние Долгов** - Карточка для каждого дилера с его долгом
- **Детали Реализации** - Информация по товарам в реализации

### 5. Отслеживание Реализации (Realization Tracking)

Список товаров, отгруженных в реализацию:

- Статус: PENDING, PARTIAL, COMPLETED, CANCELLED
- Может быть расширена (нажать на строку) для просмотра деталей
- Кнопка "Добавить Платёж" для учёта платежей дилера

## Как работает Реализация

### Со стороны дилера:

1. Вместо кнопки "Оформить заказ" дилер может нажать "Запрос на реализацию"
2. Товар отгружается дилеру
3. Дилер продаёт товар в течение оговоренного времени
4. Дилер платит столько, сколько продал

### Со стороны админа:

1. На вкладке "Реализация" видны все товары в реализации
2. Админ может добавлять платежи по мере их поступления
3. Статус автоматически меняется:
   - PENDING → Нет платежей
   - PARTIAL → Часть оплачена
   - COMPLETED → Полностью оплачена

## База Данных

### Новые таблицы:

- `Realization` - Основная запись о реализации
- `RealizationItem` - Товары в реализации
- `RealizationPayment` - Платежи по реализации

### Новые поля:

- `ProductGroup.costPrice` - Себестоимость всех товаров группы (для расчёта прибыли)

## Примечания

- Товар без группы не отображается в публичном каталоге и не может быть заказан
- Себестоимость задаётся один раз на группу товаров (в админке, раздел "Группы")
- Статусы реализации обновляются автоматически при добавлении платежей
- Все суммы в MDL (молдавские леи)

# AR — «Оживление сувениров»

Раздел **🔮 AR** в админке (только SUPER_ADMIN). Клиент сканирует QR на сувенире → открывается `/ar/{slug}` → камера распознаёт сам сувенир как маркер → поверх него появляется видео, 3D-модель или анимация.

## Типы контента

| Тип | Что показывает | Для чего |
| --- | --- | --- |
| **Видео на маркере** | видео-текстура на поверхности сувенира | магниты, открытки |
| **3D-модель (GLB)** | статичная модель, стоящая на маркере | открытки |
| **Анимация (GLB)** | GLB со встроенными клипами | открытки, персонажи |

## Как создать оживление

1. **Название** — по нему создаётся папка в Dropbox (`/ar/<Название>/`), поэтому заполняется первым: до него загрузка ассетов заблокирована.
2. **Slug** — подставляется из названия. Попадает в ссылку и QR. **После печати QR менять нельзя** — напечатанные коды перестанут работать.
3. **Тип контента** — форма сама покажет только те поля, которые к нему относятся.
4. **Изображение-маркер** — фото/скан лицевой стороны сувенира.
5. **«Скомпилировать из загруженного маркера»** — соберёт `.mind` прямо в браузере и загрузит. Занимает от нескольких секунд до минуты.
6. **Контент** — видео (mp4/webm) либо `.glb`.
7. **QR** → скачать PNG (для превью) или SVG (для типографии), напечатать не меньше 2×2 см.

## Требования к маркеру

Распознаётся не сувенир как предмет, а конкретная картинка на нём.

- **Хорошо:** детальный контрастный несимметричный рисунок, мелкие детали, текст, QR-код (у него много резких углов — он помогает).
- **Плохо:** однотонные заливки, простые лого, повторяющиеся узоры, только текст, тонкие линии, симметрия (не определится ориентация), глянец с бликами.
- Печать матовая; при тестах не наводите на изображение на мониторе — блики, подсветка и муар сильно портят трекинг.

## Фигурные сувениры (магнит по контуру страны и т.п.)

Заливайте маркером **PNG-высечку с прозрачным фоном** — видео само обрежется по силуэту: обрезка берётся из альфа-канала маркера. У прямоугольного маркера прозрачности нет, и обрезка не включается.

Видео монтируйте **в том же кадрировании и пропорциях**, что и маркер, иначе картинка внутри силуэта окажется смещена.

Отдельное поле «Маска-силуэт» (в свёрнутом блоке) нужно в одном случае: маркер сведён на непрозрачный фон ради трекинга — тогда силуэт брать неоткуда.

## 3D-модели

- Формат — `.glb`. **Draco/KTX2-сжатие не поддерживается**, экспортируйте обычный.
- Модель автоматически вписывается в размер маркера и ставится на него вертикально, поэтому «Поворот X = 0» — уже стоящая модель. Развернуть лицом — «Поворот Z» (π ≈ 3.14 — на 180°).
- Если `.glb` без встроенных текстур (частый случай у фотограмметрии) — загрузите атлас в поле **«Текстура модели»**.
- Держите файл в пределах ~10–20 МБ: он качается с телефона по мобильной сети.

### Анимация из Blender

Экспорт `glTF 2.0` → **glTF Binary (.glb)**:

- **Data → Mesh**: ✔ Apply Modifiers
- **Animation**: ✔ Animation, Mode **Actions**, ✔ Bake All Objects Animations (обязательно при IK/констрейнтах/драйверах), ✔ Always Sample Animations
- **Compression: выключить**

Переносятся ключи трансформов, скелетная анимация и shape keys. **Не переносятся** физика, частицы и анимация материалов — их надо запекать.

Сейчас проигрываются **все клипы сразу**, поэтому держите один клип на файл.

## Аналитика и управление

- **Счётчик сканирований** — растёт один раз за сессию посетителя.
- **Активен** — выключенный опыт отдаёт заглушку; напечатанные QR остаются, но «спят».
- Фильтры над списком — по типу контента и типу привязанного товара.

## Диагностика

Если на каком-то устройстве кадр камеры едет или контент не привязывается — откройте `/ar/{slug}?ardebug=1`: панель покажет размеры вьюпорта, контейнера, видео и canvas, fov/aspect камеры и габариты плоскости контента.
